# Zen PWA

Una aplicación web progresiva (PWA) enfocada en la relajación, con dos modos principales de interacción diseñados con mecánicas suaves, colores variables y físicas simples en HTML5 Canvas.

## Características

- **Diseño Mobile-First**: Súper responsivo y optimizado para pantallas de móviles.
- **PWA Instalable**: Se puede instalar desde el navegador Chrome como una aplicación nativa.
- **Modos de Juego**:
  - **Arquería Zen**: Disparos automáticos hacia polígonos que se rompen suavemente. Un modo pasivo y relajante con mejoras graduales.
  - **Caos de Rebotes**: Un entorno de físicas dentro de un círculo donde las pelotas rebotan sin perder energía, permitiendo interactuar con variables para generar patrones caóticos o armoniosos.
- **Estética Relajante**: Transiciones de colores suaves y sin distracciones (Dark/Neon vibe).

## Instalación y Desarrollo

1. Abre la terminal en la carpeta del proyecto.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Para compilar la versión de producción:
   ```bash
   npm run build
   ```

## Tecnologías Utilizadas

- HTML5 (Canvas API)
- CSS (Vanilla, variables para colores dinámicos)
- JavaScript (Vanilla)
- Vite (Empaquetador y PWA Plugin)
